# IThub academic performance

Сервис импортирует отчёты успеваемости из Excel в PostgreSQL и формирует документы на основе данных БД.

## Запуск

```bash
npm install
npm run dev
```

Перед запуском проверьте `DATABASE_URL` в `.env`. Контракт базы находится в `src/prisma/contract.prisma`; после его изменения обновите артефакты командой `npm run prisma:contract:emit` и примените миграции командой `npm run prisma:db:migrate`.

## Импорт

Откройте `/` и загрузите `.xlsx`-выгрузку. Импорт читает лист «Отчет» и сохраняет записи успеваемости вместе с партией загрузки.

## Экспорт

Откройте `/exports` и выберите документ. Для ведомости по дисциплине укажите группу, семестр, дисциплину и форму контроля. Специальность и квалификация берутся из программы группы или из формы.

Оценка в ведомости берётся из поля «Конечные баллы (5-зн система)». Если один и тот же студент повторно импортирован для той же дисциплины и семестра, используется запись из последней загрузки.

### API остальных документов

- `GET /api/export/documents` возвращает идентификаторы и имена файлов.
- `GET /api/export/document-students?groupId=1&semesterId=2` возвращает студентов для персональных документов.
- `POST /api/export/documents/:id` возвращает файл Excel или Word. В JSON можно указать `groupId`, `semesterId`, `disciplineId` и `studentId`. Для выбора студента нужны группа и семестр. Пустой запрос формирует черновик.

Генератор читает доступные записи из PostgreSQL. В черновиках отсутствующие сведения обозначены как `[Нет данных: …]`. Сводная ведомость показывает дисциплины с записями успеваемости. Для её полного заполнения нужны учебный план на семестр и формы контроля. Результаты экзаменов по ПМ и оценки за защиту курсовых требуют отдельных сведений.
