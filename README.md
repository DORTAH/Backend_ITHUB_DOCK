# IThub academic performance

Сервис импортирует отчёты успеваемости из Excel в PostgreSQL и формирует документы на основе данных БД.

## Запуск

```bash
npm install
npm run dev
```

Перед запуском проверьте `DATABASE_URL` в `.env`. Контракт базы находится в `src/prisma/contract.prisma`; после его изменения обновите артефакты командой `npm run prisma:contract:emit` и примените миграции командой `npm run prisma:db:migrate`.

## Импорт

Откройте `/` и загрузите `.xlsx`-выгрузку. Импорт читает лист «Отчет» и сохраняет записи успеваемости вместе с партией загрузки.

## Экспорт

Откройте `/exports`. Сейчас доступна «Ведомость по дисциплине, предмету» из `other/Ведомость по дисциплине, предмету.xlsx`. Для формирования выберите группу, семестр и дисциплину. Специальность и квалификация берутся из программы группы, если она настроена; иначе их можно указать в форме. Форма контроля указывается вручную, так как в исходной выгрузке успеваемости этого поля нет.

Оценка в ведомости берётся из поля «Конечные баллы (5-зн система)». Если один и тот же студент повторно импортирован для той же дисциплины и семестра, используется запись из последней загрузки.

## Справочники для следующих форм

В контракте предусмотрены учебные программы, дисциплины ФГОС и их сопоставление с дисциплинами IThub, а также назначение лицензии студенту на семестр. Таблицы готовы для последующих загрузок справочных файлов.

Другие шаблоны из `other` пока требуют дополнительных источников: расписания и посещаемости, учебных планов и соответствий ФГОС, графиков практик, тем курсовых проектов, работодателей и состава комиссий. Эти значения не выводятся из отчёта успеваемости автоматически.
