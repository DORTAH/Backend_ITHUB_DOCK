# Недостающие данные для экспорта документов

Генератор читает данные из PostgreSQL. Список составлен по текущей схеме БД и полям шаблонов. Заполненность рабочей БД отдельно не проверялась.

## Ведомости и аттестация

| Документы | Недостающие данные |
| --- | --- |
| Ведомость по дисциплине и сводная зачётно-экзаменационная ведомость | Привязка группы к конкретному учебному плану. Порядковый номер семестра по плану для выбранного календарного периода. Перечень дисциплин на этот семестр и форма контроля по каждой. Дата контроля, назначенный аттестующий преподаватель и статус при отсутствии оценки. Для сводной также нужны правила учёта этих статусов при расчёте успеваемости и качества. |
| Допуск, ведомость и сводная ведомость по ПМ | Состав профессионального модуля с привязкой МДК, учебной и производственной практики. Часы по плану, оценка по каждому компоненту, если её ещё нет в записях успеваемости, статус допуска, отдельная оценка за экзамен, итоговая оценка по ПМ и дата экзамена. |
| Приказ об утверждении экзаменационной комиссии | Номер и дата приказа, дата экзамена, форма обучения и подписант. |

## Расписания, журнал и курсовые

| Документы | Недостающие данные |
| --- | --- |
| Расписание занятий | День или дата, номер и время пары, назначенный преподаватель, площадка, аудитория и чередование недель, если оно используется. |
| Расписание промежуточной аттестации | Даты консультаций и экзаменов, назначенный аттестующий преподаватель, аудитория и дата утверждения. |
| Журнал занятий | Даты, темы и часы фактических занятий. Посещаемость и оценки студентов по каждому занятию. |
| Курсовой проект и приказ о закреплении тем | Утверждённая тема и руководитель по каждому студенту, содержание задания, дата выдачи и срок сдачи, номер и дата приказа. |
| Расписание и ведомость защиты курсовых | Дата, время и аудитория защиты, преподаватели на защите, отдельная оценка за защиту каждого студента. |

## Практика

| Документы | Недостающие данные |
| --- | --- |
| График практик, договор и приказ о направлении | Вид и код практики по плану, сроки и часы, распределение студентов по профильным организациям, реквизиты организаций и представители сторон, руководители практики, номера и даты договора и приказа. |
| Аттестационный лист, дневник и отчёт по практике | Задания и компетенции, фактически выполненные работы с датами и часами, оценки руководителей и итог практики. Для полного отчёта также нужно содержание от студента. |

## Остальные документы

| Документы | Недостающие данные |
| --- | --- |
| Ведомость выдачи доступа к ЭБС | Логин Юрайт по каждому студенту. |
| Протокол заседания кафедры | Номер и дата заседания, кафедра и руководитель, участники, повестка, рассмотренные материалы, результаты голосования и принятые решения. |

Для ведомостей, приказов и расписаний также нужны ФИО подписантов и даты подписания или утверждения там, где их требует форма.

## Записи, предусмотренные в схеме

Для выбранных групп и семестров нужно подтвердить наличие следующих записей:

- Полный состав группы и курс студентов.
- Связь группы с программой, специальностью и квалификацией.
- Однозначные сопоставления дисциплин ITHub с индексами ФГОС.
- Утверждённый состав комиссии с ролями и должностями.
